# Зимний арк — офлайн-версия

Трекер: задачи по целям (до 5 в день), каждые 3 галочки дают дырочку на карточке-награде.
Работает без интернета, данные хранятся на устройстве. Кнопки «Скачать копию» / «Загрузить копию» внизу — чтобы перенести прогресс или сохранить резервную копию.

Файлы: `index.html`, `manifest.json`, `sw.js`, иконки `*.png`. Выложить можно целиком папку на любой статический хостинг (Netlify Drop, Cloudflare Pages, GitHub Pages).
